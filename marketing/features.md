<!-- feature-intro -->
Automatically sign in a nominated Craft user from an approved IP address, Basic Authentication username or private URL key, so trusted people can skip the login screen in local development and other controlled environments.
<!-- feature-intro-end -->

<!-- feature-section -->
## Save time with logins

Let selected users sign in to the front end or control panel without entering their username and password each time. It is particularly handy for local development and other controlled environments.
<!-- feature-section-end -->

<!-- feature-grid -->
- :icon[key] **URL keys** Give a user a unique private URL that signs them in when they visit it.
- :icon[network] **IP allowlists** Restrict automatic login to approved addresses.
- :icon[lock] **Basic Authentication** Map an HTTP Basic Authentication username to a Craft account.
- :icon[route] **Choose the destination** Send the signed-in user to the public site, the Craft dashboard or another page you choose.
- :icon[settings] **Project configuration** Keep mappings and behaviour in a PHP config file alongside the rest of the project.
<!-- feature-grid-end -->
