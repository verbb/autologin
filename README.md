<h1 align="center">Autologin for Craft CMS</h1>

Autologin is a Craft CMS plugin that signs a nominated Craft user in when a trusted request matches your configuration. Use private URL keys, approved IP addresses, or HTTP Basic Authentication for controlled access and development workflows.

Map a difficult-to-guess URL key to a Craft account and share a link that signs that user in. Choose the site or control panel destination and revoke access by replacing or removing the key.

## Features

- Sign a mapped user in from a unique URL and revoke the link through configuration.
- Automatically recognise nominated users when requests arrive from approved addresses.
- Map an HTTP Basic Authentication username to a Craft account.
- Send the signed-in user to the public site or directly to the Craft dashboard.
- Choose the destination that should follow a successful automatic login.
- Keep mappings and behaviour in a PHP config file alongside the rest of the project.
